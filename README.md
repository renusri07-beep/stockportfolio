# stockportfolio # 📊 Stock Portfolio Tracker using Python

## 📌 Description
This project calculates the total investment value based on user input for stock names and quantities.

## 🚀 Features
- Predefined stock prices
- User input for stock and quantity
- Calculates total investment
- Saves result to file

## 🛠️ Technologies Used
- Python
- Dictionary
- File handling

## ▶️ How to Run
1. Open terminal
2. Run:
   python stock_tracker.py
3. Enter stock details

## 📷 Sample Output
Enter stock name: AAPL  
Enter quantity: 2  
Total Investment: 360
